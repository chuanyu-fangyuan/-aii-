# 部署到魔搭创空间 · 操作步骤

> 目标：让演示站（GitHub Pages）的 AI 问答真正连通到一个**在线、国内直连、不绑卡**的后端。
> 全程你只需要做「创建空间、拿令牌、点几下设置」，代码和脚本我已经备好。

---

## 前提（你已经完成的）

- 注册魔搭账号（https://modelscope.cn ，用阿里云/支付宝/手机号登录）
- 绑定阿里云账号 + **实名认证**（Docker 类型空间必须，否则无法构建镜像）

---

## 一次性配置（约 10 分钟）

### 第 1 步 · 创建创空间

1. 打开 https://modelscope.cn/studios → 右上角「创建创空间」
2. 填写：
   - **名称**（英文小写 + 连字符）：例如 `ai-daily-brief`
   - 显示名称：AI 情报站 API
   - **可见性**：先选「非公开」，验证通过后再改成公开（安全起见）
   - License：MIT
3. 创建即可，**运行环境先不用管**（后面在设置里选）

### 第 2 步 · 拿访问令牌

1. 打开 https://modelscope.cn/my/myaccesstoken
2. 「新建访问令牌」→ 起个名字（如 deploy）→ **复制保存**（只显示一次）

### 第 3 步 · 推送代码（在本机 Git Bash 里跑）

```bash
cd /d/开发测试/ai-daily-brief

# 先 dry-run：只组装、打印内容，不推送（确认无误再走真的）
DRY_RUN=1 MS_SPACE=你的用户名/ai-daily-brief bash deploy/modelscope/sync.sh

# 正式推送（替换成你的用户名、空间名、令牌）
MS_SPACE=你的用户名/ai-daily-brief MS_TOKEN=你的令牌 bash deploy/modelscope/sync.sh
```

> 脚本做的事：用 `git archive` 导出干净的项目（自动剔除临时产物），
> 把 `deploy/modelscope/` 里的 Dockerfile（7860 端口）和 README 覆盖到根目录，
> 然后 force-push 到创空间仓库的 `master` 分支。

### 第 4 步 · 在创空间设置部署参数

进入你的创空间 → 右上角「设置」（或「部署设置」）：

| 配置项 | 填什么 |
|---|---|
| 运行环境 / SDK 类型 | **Docker** |
| 云资源 | **免费 CPU**（`platform/2v-cpu-16g-mem`，2 vCPU + 16GB） |
| 端口 | **7860** |
| 环境变量 | 添加 `DEEPSEEK_API_KEY` = 你的 DeepSeek 密钥 |

> 环境变量在「设置 → 环境变量管理」里加，**只填 Key 本身，别把网址带进去**。

### 第 5 步 · 点「重新部署 / 上线」

等几分钟（构建镜像 + 装依赖 + 下载嵌入模型）。
看日志到这一行就说明起来了：

```
Uvicorn running on http://0.0.0.0:7860
```

### 第 6 步 · 验证

- 创空间页面能打开 → 服务已启动
- 浏览器访问 `你的空间公网地址/health` → 返回 `{"status":"ok", ...}` 且 `news_count > 0`

> 空间的**公网访问地址**在创空间页面能看到（部署成功后会分配，形如 `https://<用户名>-<空间名>.xxx`）。
> 把它复制下来，下一步要用。

### 第 7 步 · 让演示站指向它

1. 打开 GitHub 仓库 → `Settings` → `Secrets and variables` → `Actions` → 切到 **Variables** 标签
2. 新建（或编辑）变量：
   - Name：`AI_API_BASE`
   - Value：你的空间公网地址（**不带末尾斜杠**），例如 `https://xxx-ai-daily-brief.xxx`
3. 等下一次 `update.yml` 运行（每 3 小时），或手动触发一次：
   - `fetch.py` 会重新生成 `web/config.js`，把地址写进去并提交 → 前端问答即指向魔搭
   - 同时 CI 里的保活步骤会**每 3 小时 curl 一次 `/health`**，顺带防止空间休眠

到这一步，打开演示站点一个提问，答案就是从魔搭后端返回的了。

## 日常更新

| 要更新什么 | 怎么做 |
|---|---|
| 新闻数据 | 不用管 —— GitHub Actions 每 3 小时更新仓库里的 `news.db`；**空间重启时** `start.sh` 会自动拉最新版 |
| 代码 / 提示词 | 改完重新跑一遍第 3 步的 `sync.sh` 推送即可 |

---

## 常见坑（按出现频率排序）

1. **空间起不来 / 一直部署中**
   看创空间的「日志」。八成是：① 端口没选 7860 ② 运行环境没选 Docker ③ 构建网络问题（重试一次）。

2. **`/health` 正常但 `/ask` 提示"API Key 未配置"**
   `DEEPSEEK_API_KEY` 没配或配错了。去「设置 → 环境变量」确认。**改了环境变量要重新部署才生效**。

3. **前端提问报 CORS / 连不上**
   多半是 `AI_API_BASE` 填错（多了斜杠、或是填成了页面地址而不是 API 地址）。
   先在浏览器直接访问 `AI_API_BASE + /health`，通了就说明地址对。

4. **首问卡十几秒**
   不该出现（模型构建期已下载进镜像）。如果出现，说明构建时模型没下载成功，看构建日志确认 `embedding model cached` 那行。

5. **数据是好几天前的**
   重启一次空间，`start.sh` 会拉最新 `news.db`。
